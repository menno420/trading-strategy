## Ownership model

Single-owner project: menno420 owns all components. src/ owns all computation; data/ is owned by the data-loading module in src/ (only it writes cached datasets); docs/ is owned by whoever changes behavior (docs update in the same PR); control/ follows the fleet protocol in control/README.md — control/inbox.md is manager-owned (never edited by this project), control/status.md is project-owned.
